# 節奏擊點小遊戲 for YouTube Music

在 [music.youtube.com](https://music.youtube.com) 播放頁面右下角疊加一個 osu 風格的節奏點擊小遊戲，音符依播放進度與自訂拍速（BPM）出現。

## 這個擴充套件「不會」做什麼

- **不會擷取、錄製或下載** YouTube Music 播放的音訊串流。
- **不會顯示**任何受版權保護的歌詞文字——音符上只會出現通用符號（♪ ★ ● ◆ 等）。
- **不會**對外送出任何資料，也不需要帳號、登入或任何權限（`manifest.json` 除了讀取 `music.youtube.com` 頁面內容外沒有申請其他權限）。

它只讀取頁面上 `<video>` 元素本來就公開的播放進度（`currentTime` / `paused` 屬性）來對齊畫面，節奏（BPM）由你自己輸入，或用「Tap Tempo」跟著音樂點出來——因為擴充套件本身不會分析真正的音訊波形，所以無法自動抓出歌曲的真實拍子，這是刻意的設計，用來避免任何擷取音訊內容的疑慮。

## 安裝方式（開發者模式，未上架 Chrome 線上應用程式商店）

1. 開啟 Chrome，前往 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 點「載入未封裝項目」，選擇這個資料夾（`youtube-music-rhythm-extension/`）
4. 打開 [music.youtube.com](https://music.youtube.com) 播放任何一首歌，右下角會自動出現浮動面板

## 使用方式

1. 輸入 BPM，或按「Tap Tempo」跟著歌曲節奏點幾下抓拍
2. 按「開始」，音符會依拍速陸續出現
3. 滑鼠／觸控點擊音符，或按 `Z` / `X` 鍵擊發（準星會跟著滑鼠移動）
4. 面板標題列可拖曳搬移位置，右上角可最小化或關閉

## 已知限制

- **BPM 是人工設定的近似值**，不是分析真實音訊得到的精確節拍，所以不會像串流平台官方歌詞那樣逐字對拍。
- 這是用「載入未封裝項目」的開發者模式安裝，**沒有上架 Chrome 線上應用程式商店**，所以無法用一般安裝流程分享給別人，每個人都要自己手動載入。
- YouTube Music 網站的頁面結構可能會不定期改版，若 `document.querySelector('video')` 找不到播放器，面板就不會出現；屆時需要更新 `content.js` 的選取邏輯。
