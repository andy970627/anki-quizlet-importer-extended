# Odyssey — 專案總覽簡報（給接手的 AI / 協作者）

這份文件是獨立、自包含的專案簡報，整合了目前為止所有的玩法發想與實作進度。不需要讀過先前的對話記錄，直接看這份就能接手設計或開發。

## 專案是什麼

一款恐怖遊戲企劃，用荷馬史詩《奧德賽》的「永遠回不了家」架構，改寫成一個會不斷重複、永遠走不出去的迴圈恐怖遊戲。核心情緒不是血腥 Jump Scare，而是**迷失感**與**薛西弗斯式的徒勞**——玩家努力想要逃出去，但每次快成功時都會被送回起點重來。

> 一句話核心：你想回家，但海神不准你走——每次以為快逃出去了，祂就找個理由把你吹回島上。像薛西弗斯推石頭一樣，努力不會累積，只有「再試一次」。

## 神話依據（不是硬套用的裝飾，是機制設計的根據）

- **波賽頓的詛咒**：奧德修斯弄瞎了獨眼巨人波呂斐摩斯（波賽頓之子），波賽頓因此詛咒他的返鄉路充滿阻撓——這是原典裡「為什麼回不了家」的真正原因。
- **卡呂普索島（Ogygia）的七年**：奧德修斯曾被困在這座島上整整七年，哪裡都去不了。
- 兩者疊加：**玩家 = 被海神盯上、困在島上第 N 年的奧德修斯。**

## 核心玩法迴圈

```
起點（島上/地下街入口）
  → 走一段路（出海一段 / 走過一段地下街）
  → 遇到「異常檢查點」：這段場景跟正常版本比，有沒有不對勁的地方？
  → 玩家判斷：有異常要標記/往回走；沒異常要往前走
  → 判斷正確 → 進入下一段，離「出口/家」更近
  → 判斷錯誤 → 觸發海神的追逐者，被追上 = 這一輪失敗，送回起點重來
  → 連續正確通過所有段落 → 完成一周目，真正逃出去
```

這個迴圈機制直接借鏡《8 號出口（The Exit 8）》——玩家走在循環走廊裡，靠判斷「這段正不正常」決定要往前還是往回走，判斷錯誤就被送回起點。這是目前市面上公認最精簡、最適合小規模團隊複刻的「迷失恐懼」玩法範本。

## 場景設定：為什麼選台北車站地下街，而不是開放海面

「出海」是原始的比喻，但實作一片開放海面＋船隻物理，對小規模專案成本太高。改用**台北車站地下街**當場景有幾個理由：

1. 北車地下街是全台最大、最容易迷路的地下轉運系統（串聯捷運/台鐵/高鐵/公車），現實中「一走進去就迷路」是普遍經驗，場景一出來玩家就懂在怕什麼，不需要額外鋪陳設定。
2. 「巨大轉運站地下迷宮」的無方向感不是台灣獨有——東京新宿地下街、紐約中央車站地下通道都有類似惡名，是已開發國家通勤族共通的恐懼，國際受眾也能共鳴。
3. 美術成本低很多：走廊、手扶梯、售票大廳、閘門都是方塊/Tilemap 等級就能先頂著測試的場景，不需要船、海浪這類難做的素材。
4. 跟神話主線的接法：地下街迷宮 = 「海」的現代轉譯，怪物（海神化身）在玩家判斷錯誤時於通道盡頭現身追逐。

## 異常主題池（沿用奧德賽典故，當作「每輪隨機抽取的異常池」而非線性章節）

| 異常類型 | 原典依據 | 具體表現 |
|---|---|---|
| 忘憂果式誘惑 | 吃了忘憂果的人不想離開 | 場景突然變得舒適安全、有音樂聲，誘惑玩家停留——多待其實是在偷走你的進度 |
| 獨眼巨人的怒吼 | 波呂斐摩斯／詛咒源頭 | 遠方傳來怒吼，聲音接近代表怪物鎖定了你；建議偵測邏輯用「聲音/光線暴露」而非純距離（見下方敵人設計） |
| 賽蓮的歌聲 | 歌聲引誘水手觸礁 | 耳邊傳來呼喚聲，引導玩家走向看似捷徑、實則危險的方向 |
| 喀耳刻的鏡影 | 把水手變成豬 | 鏡面/倒影裡的自己表情不對、多了一隻手，玩家要自己判斷這是不是異常 |
| 冥界的低語 | 奧德修斯到陰間問路 | 傳來「過去失敗的自己」的聲音，有時是提示、有時是誤導 |

## 敵人設計：為什麼用「聲音/光線」而不是純距離偵測

獨眼巨人設定上很強、很兇，但感官不完整。對應到遊戲機制：

- 玩家開手電筒時，怪物偵測範圍大幅提升（光 = 暴露自己）
- 玩家奔跑時，短時間偵測範圍也提升（腳步聲）
- 玩家蹲下、關手電筒、靜止不動時，即使距離近也不容易被發現

這讓「手電筒電量」不只是資源管理，而是「開燈找路 vs. 被發現」的核心兩難，跟主題緊密扣在一起。

## 什麼跨輪保留、什麼歸零

- **歸零**：這一輪走過的路線、還沒標記的異常——每次失敗都重新從起點開始。
- **保留**：玩家自己記得的經驗（例如「上次那盞燈顏色不對」）；可以做一本可翻閱的「航海日誌/異常手冊」UI，自動記錄曾經標記過的異常描述；起點場景隨失敗次數累積留下視覺痕跡（讓「第幾輪」有重量感，而不是單純重播同一個開場）。
- **結局條件**：連續一輪中，正確判斷所有段落的異常、且沒被抓到，才算真正逃出去。可以做多重結局：真的到家，或到了家才發現家也不對勁（呼應「歸鄉未必圓滿」的原典主題）。

## 可以疊加的延伸玩法（還沒實作，設計發想階段）

這些是在核心迴圈之上可以挑選疊加的機制，不需要全部做：

1. **記憶迴響**：被打回起點後，場景出現「上一輪自己」的半透明殘影，重演上次的路線跟錯誤——把「薛西弗斯推石頭」字面化成「連失敗過程都要重新經歷」。
2. **手動標記地圖**：不做小地圖/導航系統，玩家自己按鍵在交叉口留記號，記錯/漏記要自己付代價，把「迷路恐懼」直接做成玩法而非背景設定。
3. **相信誰的聲音**：同時有真求救聲和誘導幻聽，玩家靠音源方向、音質異常自己判斷要不要跟隨，比單純的對錯判定題更細膩。
4. **犧牲機制**：身上道具（手電筒電量、同伴 NPC）可以「捨棄」換取立即優勢（例如丟噪音源引開怪物），不可逆、影響後續資源與結局，呼應奧德修斯丟棄同伴求生的情節。
5. **假出口**：半路出現看起來像出口的門，推開後其實是另一段循環的開始，玩家學會「不要輕易相信看起來像終點的東西」。
6. **生理回饋式緊張感**：畫面邊緣的心跳/喘息效果隨「被鎖定機率」模糊地變化，不給明確數值，逼玩家憑直覺判斷安不安全。
7. **兩難路線選擇**：強制玩家在「確定遇敵但較短」跟「安全但耗時/耗電」之間選，沒有正確答案，呼應斯庫拉與卡律布狄斯的典故。

## 目前實作進度

兩個 repo 各自有一套可運作的雛形腳本，核心邏輯相同，只是視角/引擎基礎不同：

### `odyssey-horror/`（第一人稱 3D 版本，位於 `anki-quizlet-importer-extended` repo）
- `FirstPersonController.cs` — WASD + 滑鼠環顧
- `Flashlight.cs` — 手電筒開關、電量消耗
- `EnemyChaser.cs` — NavMeshAgent 巡邏/追逐
- `ScareTrigger.cs` — 一次性驚嚇音效觸發
- `HorrorGameManager.cs` — 捕獲後重新載入場景

### `2d`（俯視角 2D 版本，獨立 repo `andy970627/2d`，分支 `claude/topdown-odyssey-prototype`）
以 Unity 官方 2D Platformer Microgame 範本為底（範本本身的跳躍/碰撞/線性終點玩法跟本企劃衝突，所以不沿用範本的 `PlayerController`/`EnemyController`，只留底層 `Simulation`/`GameController` 框架和 `InputSystem_Actions`），新增 `Assets/Scripts/TopDown/`：
- `TopDownPlayerController.cs` — 八方向移動，沿用既有 `Player/Move` 輸入
- `AnomalyZone.cs` — 異常檢查點，玩家按既有的 `Player/Jump` 鍵標記異常，離開範圍不按視為判斷「正常」，對錯都回報給 loop manager
- `CorridorLoopManager.cs` — 迴圈狀態機，記錄周目數/已通過段數，錯誤判斷觸發追逐者、被抓到送回起點
- `PursuerController2D.cs` — 海神化身，平常不動，`TriggerPursuit` 後朝玩家移動，追上即失敗

兩套腳本都還沒有美術/場景，目前只能用方塊佔位測試邏輯。

## 給接手者的建議起點

1. 先在任一版本裡把場景組起來（參考各自 repo 裡的 README），實測核心迴圈「判斷異常 → 對/錯 → 繼續或被追」好不好玩，這是目前最大的未驗證風險。
2. 美術/3D 素材如果要生成，北車地下街這類寫實現代場景用 Meshy/Tripo 這類 AI 3D 生成工具效果最好；神話生物類素材（怪物、船）生成品質較不穩定，建議走低多邊形/抽象風格降低成本。
3. 延伸玩法（上面列的 7 項）建議先驗證核心迴圈再疊加，避免還沒確定好不好玩就加太多系統。
4. 這個企劃跟另一個真實課程作業（NTUT「數位設計原理」期末，場景設定在北科光華館）共用同一套核心機制，兩邊的程式可以互通，只是場景/敘事皮不同。
